# AI-Scope

AI-Scope is an astronomical data platform designed for the era of machine learning, deep learning, and foundation models. It focuses on making large astronomical catalogs and image collections easier to query, crossmatch, visualize, and prepare for modern AI workflows. The platform is built to reduce the friction involved in working with large datasets, creating efficient dataloaders, handling catalog joins, and transforming raw survey data into products that are useful for both scientific analysis and ML-ready pipelines.

AI-Scope is not just a classical astronomy database interface. It is being developed as a practical environment for scalable astronomical data access, exploration, and preparation, with special attention to the needs of researchers building data-driven methods and foundation-model pipelines.

## Main platform pages

### Query Tool
The Query Tool is the main environment for accessing astronomical catalogs in AI-Scope. It supports both synchronous and asynchronous queries and includes extra features designed to improve performance and usability. A central part of this system is **AstroQL**, a language created to simplify astronomical querying while allowing the backend to choose optimized strategies automatically, including the best available indexes and execution paths.

**Page:** [Query Tool](https://ai-scope.cbpf.br/query)  
**AstroQL docs:** [AstroQL Documentation](https://ai-scope.cbpf.br/documentation/astroql)

### Image and File Collections
The Images page is dedicated to image and file collections made available through AI-Scope. This section is intended to support the exploration of image databases and the creation of derived products such as image stamps, colored images, and trilogy images. It is designed to make it easier to move from catalog-level exploration to visual inspection and dataset construction.

**Page:** [Images and File Collections](https://ai-scope.cbpf.br/images)

### Cone Search
The Cone Search page allows users to perform quick positional searches around celestial coordinates and rapidly inspect the results. It is useful for fast exploration, coordinate-based lookups, and quick plotting of returned data, helping users test ideas and inspect small sky regions interactively.

**Page:** [Cone Search](https://ai-scope.cbpf.br/cone-search)

### Interactive Viewer
The Interactive Viewer provides an integrated sky exploration interface based on Aladin. It allows users to inspect the sky interactively while connecting directly to AI-Scope resources, making it easier to visualize catalog content, explore fields, and combine interactive sky navigation with platform data access.

**Page:** [Interactive Viewer](https://ai-scope.cbpf.br/interactive-viewer)

### Query History
The Query History page allows users to review previously executed queries and inspect past results. This makes it easier to revisit analyses, track workflows, and recover outputs generated in earlier sessions.

**Page:** [Query History](https://ai-scope.cbpf.br/queries/history)

### Dashboard
The Dashboard gives users an overview of their account activity and platform usage. It is the place to monitor user-related information, keep track of executed jobs, and manage interaction with AI-Scope in a more organized way.

**Page:** [Dashboard](https://ai-scope.cbpf.br/dashboard)

## Full website description

AI-Scope is an astronomical data platform focused on enabling machine learning, deep learning, and foundation-model workflows. It provides optimized tools for querying large catalogs, exploring image and file collections, performing quick cone searches, visualizing the sky interactively, and tracking user activity and query results. By combining scalable data access with tools designed for crossmatching, dataloader preparation, and large-catalog handling, AI-Scope aims to make astronomy data more practical and accessible for modern computational research.
